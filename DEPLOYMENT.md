# Taproom Studio - Deployment Guide

## Quick Start (Deploy to Vercel in 2 minutes)

### Prerequisites
- GitHub account
- Vercel account (free)
- This code repository

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "Initial Taproom Studio site"
git remote add origin https://github.com/YOUR_USERNAME/taproom-studio.git
git push -u origin main
```

### Step 2: Deploy to Vercel
1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Import your GitHub repository
4. Vercel auto-detects Next.js
5. Click "Deploy"
6. **Done.** Your site is live at `taproom-studio.vercel.app`

### Step 3: Connect Custom Domain (Optional)
In Vercel project settings:
- Go to "Domains"
- Add your custom domain
- Follow DNS instructions

## Next Steps: Connect Supabase (Database)

### Why Supabase?
- Free PostgreSQL database
- Real API for form submissions
- Easy to scale with your brewery list
- Perfect for managing 9K breweries eventually

### Setup Supabase:

1. **Create Supabase Account**
   - Go to [supabase.com](https://supabase.com)
   - Sign up with GitHub
   - Create a new project

2. **Create Database Table**
   ```sql
   CREATE TABLE tap_submissions (
     id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
     brewery_name TEXT NOT NULL,
     name TEXT NOT NULL,
     style TEXT,
     abv TEXT,
     price TEXT,
     created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );
   ```

3. **Get API Keys**
   - In Supabase dashboard, go to Settings → API
   - Copy `Project URL` and `anon public key`

4. **Add to Vercel Environment Variables**
   - In Vercel project settings, go to "Environment Variables"
   - Add: `NEXT_PUBLIC_SUPABASE_URL` = your Project URL
   - Add: `NEXT_PUBLIC_SUPABASE_ANON_KEY` = your anon public key

5. **Update Code** (coming next - will add Supabase client integration)
